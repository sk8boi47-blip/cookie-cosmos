# Cookie Cosmos

A self-contained cookie-clicker game built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

In this repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. The workflow at `.github/workflows/pages.yml` deploys the site when changes reach `main`.

After Pages is enabled, add your chosen custom domain in the **Custom domain** field on that same page. If the domain is already attached to another GitHub Pages repository, remove it from that repository first. Configure the matching DNS records with your domain provider.

Game progress and audio preferences are saved in the player's browser using local storage.
